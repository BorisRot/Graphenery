# Graphenery

A Python-based simulation tool for exploring tight-binding models in 2D lattice systems, with focus on graphene-like structures and topological effects.

## Features
- Construction of lattice Hamiltonians
- Visualization and manipulation tools for lattice geometry
- Eigenvalue and mode structure analysis
- Disorder analisys

## Tech
- Python (NumPy, SciPy, matplotlib)

## Status
Fully functional – core functionalities are active and operational.
